# Dataset Setup

Obtain **Telco Customer Churn** from the [Kaggle dataset listing](https://www.kaggle.com/datasets/blastchar/telco-customer-churn), uploaded by BlastChar. The listing describes it as IBM sample data; follow the source's terms and credit the original authors as identified there.

Place the downloaded CSV in this directory with this exact filename:

```text
WA_Fn-UseC_-Telco-Customer-Churn.csv
```

The EDA script expects that path. The CSV is excluded from Git because the listing's wording, “Data files © Original Authors,” does not by itself confirm permission to redistribute the file. It may be kept locally for analysis. Do not add it to a public repository unless redistribution permission has been verified.
